What you can do here

  • Consumers — add, edit and delete credit files. Deleting one cascades to addresses, inquiries and scores.
  • Accounts — open a tradeline through the sp_open_account stored procedure, edit balances, close or delete it.
  • Audit trail — every account edit made here, recorded by the trg_account_audit trigger.
  • Analytics — set operations, set membership and comparison, WITH and recursive queries, advanced aggregates and OLAP, each showing the SQL it ran.
  • SQL console — run your own query in a read-only transaction.
